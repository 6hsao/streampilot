# StreamPilot 任务清单（Issue 级）

> 对应计划：[PLAN.md](PLAN.md) · 里程碑：M0 ~ M7
> 每条任务可直接转为一条 GitHub Issue。优先级定义：
> **P0** = 主链路或合规阻塞，必须最先完成；**P1** = 产品可用性必需；**P2** = 增强与规模化。
> 依赖列中的编号即任务 ID，未列依赖表示可并行启动。

## 任务总览
