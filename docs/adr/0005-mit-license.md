# 0005. 开源许可证采用 MIT

- 状态：Accepted
- 日期：2026-11-15
- 决策人：项目负责人

## 背景

项目以开源方式发布，希望降低采用门槛、便于生态集成，同时保留对品牌与合规的责任边界。候选为 MIT 与 Apache-2.0。

## 决策

- 采用 **MIT License**，全文见仓库根目录 `LICENSE`。
- 仓库不包含任何模型、字体、Live2D 专有运行时、音色样本或平台素材；这些资产单独授权。
- 第三方依赖按其许可证执行（详见 [OPEN-SOURCE.md](../OPEN-SOURCE.md)），并保留 NOTICE 与 LGPL 声明。

## 备选方案

| 方案 | 优点 | 不采用原因 |
| --- | --- | --- |
| MIT | 最简、最易集成、社区接受度最高 | 无显式专利授权条款 |
| Apache-2.0 | 含专利授权与商标条款 | 文本与合规义务更重，与首发“低门槛”目标不完全一致 |

## 影响

- 正面：集成门槛低；与 pixi-live2d-display 等 MIT 组件一致。
- 负面：无专利明示授权；需通过 `INF-08` 与 NOTICE 管理上游义务。
- 跟随改动：`README` 许可证章节、`GOV-06` 完成、`LICENSE` 入库。

## 依据

- 项目负责人的明确决策（2026-11-15）。
