# 0002. 数字人渲染采用 Live2D

- 状态：Accepted
- 日期：2026-11-15
- 决策人：项目负责人

## 背景

首发为单直播间、1080p30 的常态直播。需要在可控成本下获得稳定、可授权的虚拟形象，并支持实时口型、表情与动作。3D 方案对 GPU、美术与绑定要求更高；预渲染视频缺乏实时互动感。

## 决策

- 渲染技术：**Live2D**，`pixi-live2d-display`（MIT）负责渲染，Cubism Core 运行时按官方许可单独获取。
- 渲染服务运行在云端 GPU 节点（T4/A10 级），1080p30；异常时降 720p 或静态形象。
- 口型由 TTS 时间戳驱动，表情/动作由状态机调度；场景合成与 AIGC 标识在同一管线完成。
- 模型、动作、贴图存 OSS 并版本化，**不入仓库**；上播前校验授权与 manifest。

## 备选方案

| 方案 | 优点 | 不采用原因 |
| --- | --- | --- |
| 3D（VRM/自研引擎） | 表现力强、可多机位 | GPU 与美术成本高，首发单间投产比低 |
| 预渲染视频 | 成本最低 | 无实时口型与表情，互动感差 |
| 纯静态图 + 音频 | 实现最简单 | 不符合虚拟主播产品定位 |

## 影响

- 正面：成本可控、素材生态成熟、1080p30 单 GPU 可承载。
- 负面：依赖 Cubism 专有运行时与许可；模型制作是外部前置依赖（美术、绑定、动作）。
- 跟随改动：`AVT-04/05/07/08`、`GOV-07`、`COST` 的一次性投入、`LIV-09` 的许可证清单。
- 回退成本：中。渲染服务接口保持抽象，未来可替换为 3D，但美术资产需重做。
